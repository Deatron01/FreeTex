# FreeTex web app

This folder holds the FreeTex front end, built with React 19, Vite, Tailwind CSS 4, CodeMirror 6 and PDF.js. The [top-level README](../README.md) covers features and setup.

```bash
npm install
npm run dev       # development server with /api proxied to the compile server on :3001
npm run build     # production build in dist/
npm run lint
npm run server    # start ../server (needs TeX Live)
```
